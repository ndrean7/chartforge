# Trade journal template

One row per closed trade. Fill it in the same day the trade closes —
memory lies, the journal does not.

| Date | Pair | Dir | Entry | SL | TP | Size | Result (pips / $) | Plan followed? | One lesson |
|------|------|-----|-------|----|----|------|-------------------|----------------|------------|
|      |      |     |       |    |    |      |                   | yes / no       |            |

## Monthly review

At the end of each month, roll the journal up:

- Total pips:
- Number of signals / trades:
- Win rate:
- Biggest win:
- Biggest loss:
- Total risk taken vs total reward:
- Did I follow the plan on every trade? If not, which ones and why:
- One thing to repeat next month:
- One thing to stop doing next month:

The monthly review is the record. A trader who cannot show a month
like this is guessing about their own edge. See
`examples/journal-nov-2026.md` for a month written exactly this way
from the author's real Traders Family record.
